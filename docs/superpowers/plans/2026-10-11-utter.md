# Utter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Utter, a CPU-only air-gapped Linux TTS tray utility: select text with the mouse, press a global hotkey, hear it spoken by a local int8 Kokoro 82M ONNX model.

**Architecture:** One PyQt6 process owns a tray icon, a floating controller, a portal/X11 hotkey binding and a warm single `InferenceSession`. A worker thread synthesises Utter-sized text units with `kokoro-onnx` and pushes 24 kHz float32 frames into a `sounddevice` output stream; a Unix-socket control channel lets the `utter` CLI delegate to that warm process instead of loading a second model.

**Tech Stack:** Python 3.12 (uv-managed), `kokoro-onnx==0.6.1`, `onnxruntime` (CPUExecutionProvider), `numpy`, `sounddevice`, `num2words`, `PyQt6`, `jeepney`, `python-xlib`, `tomli-w`, `pytest`.

**Spec:** `docs/superpowers/specs/2026-10-11-utter-design.md` — read it before starting. Every value below comes from it; where the spec and this plan disagree, the spec wins and the plan is wrong.

## Global Constraints

- Python `>=3.12,<3.13`. `kokoro-onnx==0.6.1` is pinned: it declares `<3.14` and is the only version constraint.
- `ort.SessionOptions()`: `intra_op_num_threads = 4`, `execution_mode = ORT_SEQUENTIAL`, `enable_cpu_mem_arena = False`.
- Providers: `providers=["CPUExecutionProvider"]`, passed explicitly, always.
- The `InferenceSession` is created **once per process** and never recreated. Load lazily on first `speak`, keep forever.
- Sample rate 24000, mono, float32, everywhere.
- Unit sizing: first unit cut at the first clause mark or 60 characters, whichever comes first; all later units hard-wrapped at **80 characters**; fragments under three words merged into the neighbour; units with no alphanumeric character dropped; input over `speech.max_chars` (20000) refused before synthesis.
- Inter-unit silence: 0.25 s after a sentence-boundary split, 0.12 s after a clause or hard-wrap split.
- Normalise the whole selection **before** chunking. Never normalise after a split.
- `src/utter/` contains **no HTTP client, no telemetry, no network code**. All downloads live in `install.sh`.
- Model files and digests: `kokoro-v1.0.int8.onnx` `6e742170d309016e5891a994e1ce1559c702a2ccd0075e67ef7157974f6406cb`, `voices-v1.0.bin` `bca610b8308e8d99f32e6fe4197e7ec01679264efed0cac9140fe9c29f1fbf7d`.
- `tts/*` must not import `ui/*` or PyQt. `ui/*` must not import `onnxruntime`.
- Defaults: voice `af_heart`, speed 1.0, lang `en-us`, phonemizer `espeak`, normalize true, log level `info`.
- Control socket: `$XDG_RUNTIME_DIR/utter.sock`, mode `0600`, JSON-lines.
- Tests never touch the real `~/.config`, `~/.local/share` or `~/.local/bin`; always use a `tmp_path` XDG root via the `UTTER_*` env overrides.
- Commit after every task. Never `git add -A` blindly; add the files the task touched.

## Review Focus

Five input classes the spec implies but does not enumerate. Each gets a test in the task that owns the code.

1. **A selection that is one unbroken token** (`"a"*300`, a long URL, a hashed filename): must wrap, synthesise and play — never hang, never raise, never produce a silent unit.
2. **A currency amount straddling a split point** (`"It costs $1,234.56 today"` where the 60-character first-unit cut lands inside the amount): must be normalised before chunking, so the amount is never spoken as two fragments.
3. **Hotkey pressed twice inside one unit's synthesis** (second press while the first text is still being synthesised): the second text must win, and no audio from the superseded text may be heard afterwards.
4. **The output device disappearing mid-utterance** (Bluetooth headset unplugged, suspend/resume): must stop cleanly, keep the process alive, and work on the next `speak`.
5. **A selection of only punctuation, only emoji, or only whitespace**: no crash, no spurious audio, at most one tray message.
